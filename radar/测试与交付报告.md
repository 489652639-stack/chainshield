## 本版真正实现的能力

新闻RSS → 30分钟内两个独立网站提及同一实体 → DexScreener匹配24小时内SOL交易池 → 复用链盾关键权限/风险初筛 → Jupiter V2双向报价 → 自动模拟买入 → SQLite持仓 → 止盈、止损或高危异常模拟退出。

四个中文页面：热点雷达、链盾检查、自动交易、系统设置。支持BNB/SOL/ETH手动风险查询，自动模拟限SOL。模拟本金每笔约100元人民币；实际按参考汇率换算美元稳定币，并明确显示费用/滑点模型。服务器独立运行，手机只负责查看和控制。此版本没有私钥、签名器或实盘广播入口。

## 真实接口验证

`evidence/live-api.json`和`evidence/ci-live-api.json`保留本地及云端独立探针。都只读取数据，签名/广播次数为0。

- GoPlus：SOL、BNB、ETH样本返回有效数据。
- Honeypot.is：BNB和ETH成熟样本返回供应商模拟结果。
- RugCheck：SOL样本报告可读。
- DexScreener搜索：真实返回交易对列表。
- Jupiter V2 `/order`：无taker的只读报价成功；样本USDC→SOL返回feeBps=2。这只是该次样本的平台费，不是新币或全流程总费用承诺。
- 新闻RSS和人民币参考汇率可连接；默认新闻源为BBC与Guardian世界新闻。
- 原候选A写的DexScreener WebSocket地址：升级握手403、未成功升级。探针`ok`表示检查执行完成；**不表示该WebSocket可用**。系统使用官方HTTP搜索接口。

实际接口可连接不等于实际新币可成交。此次没有自然形成一条合格“真实热点→新币→初筛通过→模拟买卖”交易记录，也没有真实资金成交。新币缺少关键权限或费率证据时会跳过，可能导致很少或没有买入；不能为了生成交易记录把未知改成安全。

## 本版未完成的事项

1. 尚未接入X、Telegram等社交平台真实授权源；简单新闻实体提取不覆盖全部中文、别名和新梗，同名币也可能毫无真实关联。
2. 没有实盘签名、广播、成交确认和链上实际卖出验收；后续需要独立授权并继续开发/审核，配置改成live会拒绝启动。
3. BNB自动交易及OKX DEX独立连接器未开发；BNB/ETH目前仅手动查询。
4. 只有报价记账模拟，0.5%滑点与每边0.03USDC网络费用是明确假设；未覆盖真实交易的全部成本、MEV、失败率、ATA租金和稳定币脱锚。
5. 没有用户云主机连接入口、域名或HTTPS证书，尚未部署到阿里云/腾讯云。安装APK后需要先部署后台并在系统设置填写服务器HTTPS地址与访问密钥，才能使用实时功能。
6. 没有在用户OPPO实体机、中国大陆实际网络、Android16实体设备做验收。供应商接口、额度和免费政策可能变化。
7. 使用调试签名；生产长期发布需要固定签名、更新机制以及补齐Android备份规则/图标等发行项。本版不保证盈利、永久可用或完全无Bug。
