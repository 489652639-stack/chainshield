## A项目必须修复的具体位置

- `src/scanner/websocket-discovery.ts:25`：把HTTP GET路径写成WebSocket。本次升级握手得到HTTP403，没有升级成功；官方文档仅公布该路径HTTP GET，不能据此断言任何网络上永远不支持，但本环境未验证可用。
- `src/exit/executor.ts`：`Live exit execution not yet implemented`；紧急退出仍进入这条缺失路径。
- `src/bot/orchestrator.ts`：实盘成功后保留`TODO: Create position in database`，可能有买单却没有被持仓监控接管。
- `src/safety/goplus.ts`：`mintable?.status ?? '0'`等把缺失值变成无权限；简化结构未保留所有Token-2022限制。
- `tsconfig.json`：ESNext与node16解析设置冲突，npm run build失败。修复这一行不代表其他类型或运行问题自动解决。
- 依赖安装先禁用了生命周期脚本；本地Node24测试受better-sqlite3原生绑定未构建影响，不能把这部分失败全归因于业务代码。非integration测试记录：19文件中7通过、12失败，测试汇总210通过、100失败（报告总计327，另有套件未能执行）；测试不是299项全部通过。另有退出状态转换、配置预期、接口字段断言等独立失败。云端Node20完成原生SQLite构建后复验：327项中297通过、30失败，测试退出码1；编译仍然TS5110、退出码2，详见evidence/candidate-a-ci-node20。
- `npm audit`针对本次解析的依赖图报告20项漏洞：4 critical、10 high、6 moderate；很多在开发工具中，不能直接推定存在私钥窃取。没有上游根锁文件保证相同解析结果。

## 精简复用方案及剩余工作

已复用链盾三链数据获取、校验和中文风险归一化；新增标准库SQLite热点去重、名称关联、JupiterV2只读报价、模拟账本、止盈止损、鉴权服务和4页中文安卓端。API不可用则等待或显示未知，不添加假数据兜底。

首版为**新闻热点驱动的SOL模拟交易**，不是完整生产实盘成品。简单实体提取会漏掉中文新闻、新梗和语义别名；同名币可能是冒牌。尚缺X/Telegram等真实授权社交源、实盘签名及完整成交确认、BNB自动交易、云主机部署和双云迁移实测。HTTP可连接不等于通过整个真实热点→新币→安全→成交链路验收。
